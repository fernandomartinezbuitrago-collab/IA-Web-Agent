# 🤖 AI Web Design & Deploy Agent

Este proyecto es un agente de Inteligencia Artificial capaz de diseñar, programar y desplegar Landing Pages profesionales de forma autónoma.

## 🚀 Características
- **Generación de UI:** Diseños modernos usando Tailwind CSS.
- **Cumplimiento Legal:** Inserción automática de banners de cookies y secciones legales (GDPR).
- **Despliegue Automático:** Conexión directa con Vercel para publicar la web en segundos.
- **Tecnología:** Desarrollado con LangChain, OpenAI (GPT-4o) y E2B Sandbox.

## 🛠️ Instalación
1. Clona el repositorio.
2. Instala las dependencias: `pip install langchain-openai e2b-code-interpreter python-dotenv`.
3. Crea un archivo `.env` con tus credenciales:
   - `OPENAI_API_KEY`
   - `E2B_API_KEY`
   - `VERCEL_TOKEN`
